# Navidad Latina

Tema festivo para **Omarchy 4**, con colores inspirados en la Navidad
latinoamericana, un fondo original y fotos de alumbrados en Colombia y Mexico.
Probado en Omarchy 4.5.

## Instalacion

```bash
omarchy theme install https://github.com/ciprianotoor/omarchy-navidad-latina-theme.git
```

El comando instala y activa el tema. Para recorrer sus fondos:

```bash
omarchy theme bg next
```

## Borde animado rojo, azul y blanco

La animacion es opcional; instalar un tema no ejecuta scripts del repositorio.
Para instalar los hooks de Omarchy que activan el borde al usar este tema y al
iniciar sesion:

```bash
bash ~/.config/omarchy/themes/navidad-latina/install-border-lights.sh
```

Los hooks solo ejecutan el efecto con `navidad-latina` activo y lo detienen al
cambiar a otro tema. No instala paquetes adicionales.
